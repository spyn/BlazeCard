# No Google.Apis.Walletobjects client library

BlazeCard does not call the Google Wallet API (offline, preview-only). Google **Code Snippets** are produced from local DTOs/templates as a full annotated HTTP envelope plus body. We dropped `Google.Apis.Walletobjects.v1` (and Auth) to avoid unused client/auth surface and dependency drift. Image URIs in the Google snippet are placeholder HTTPS URLs, not session data URIs.
